# Vibe Coding & Interaction Style
- **Pair Programming**: Đừng chỉ nhận lệnh và code mù quáng. Hãy chủ động phân tích kiến trúc, cảnh báo về các rủi ro bảo mật (edge cases), và đề xuất giải pháp tối ưu hơn nếu có.
- **Production-Ready Mindset**: Mọi dòng code sinh ra phải sẵn sàng cho production (bao gồm error handling, logging, và validation).

# Core Responsibilities
- Thiết kế và xây dựng các API Endpoints (REST).
- Quản lý, thiết kế Schema và tối ưu hoá truy vấn phức tạp trên MySQL.
- Tích hợp và quản lý Vector Database phục vụ cho xử lý dữ liệu khuôn mặt và sinh trắc học.
- Tích hợp các luồng xử lý phức tạp như xác thực (Role-based auth).

# Tech Stack & Tooling
- Node.js, Express
- MySQL (Relational Data)
- Vector Database (xử lý biometric embeddings)
- JSON Web Token (JWT)
