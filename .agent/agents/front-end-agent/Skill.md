# 1. Advanced Next.js Features
- Xử lý mượt mà Server-side Rendering (SSR), Client-side Rendering (CSR). 
- Xây dựng Middleware định tuyến phân quyền chuẩn xác.

# 2. Client-side Integrations & APIs
- Kết nối thành thạo Fetch API với token JWT, tự dọn dẹp (cleanup effects) kết nối để tránh memory leak.
- Truy vấn webcam thực tế, quản lý MediaStream an toàn.

# 3. Accessibility (a11y) & Core Web Vitals
- Tối ưu semantic HTML, phân rõ cấu trúc thẻ heading (h1-h6).
- Cải thiện tối đa LCP (Largest Contentful Paint), CLS (Cumulative Layout Shift) để trang tải ứng dụng mượt mà không bị giật lag khung hình.
